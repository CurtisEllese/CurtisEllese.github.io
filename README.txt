Сайт для Нуры — черновая версия.

Как открыть:
1) Откройте index.html в браузере.
2) Для публикации загрузите всю папку nura_love_story на Vercel / Netlify / GitHub Pages.

Структура:
- index.html — весь дизайн, тексты и анимации.
- assets/ — фотографии.

Места, которые специально оставлены для следующего этапа:
- дополнительная совместная фотография в галерее;
- ваша песня (название, исполнитель, обложка, при желании аудиофайл);
- можно заменить любую фотографию в существующих блоках.
